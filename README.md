# 🍔 برغر تاون — Burger Town

موقع مطعم برغر عصري بتصميم عربي **RTL**، يقدّم تجربة واجهة تفاعلية لعرض قائمة الطعام، الوجبات الأكثر طلباً، العروض الخاصة، وآراء العملاء، مع سلة تسوق وتفاعلات ديناميكية داخل الصفحة.

## ✨ عن المشروع

**برغر تاون** هو مشروع Front-End لموقع مطعم برغر، تم تصميمه ليجمع بين المظهر العصري وسهولة الاستخدام وتجربة تصفح ممتعة.

الموقع يستخدم واجهة عربية بالكامل مع دعم اتجاه **RTL**، ويحتوي على قائمة طعام مقسمة إلى عدة تصنيفات، بالإضافة إلى العروض وسلة التسوق والتفاعلات المختلفة.

# 🍔 Burger Town

A modern **RTL Arabic burger restaurant website** designed to provide an interactive experience for browsing the menu, discovering popular meals, checking special offers, reading customer reviews, and using a dynamic shopping cart.

## ✨ About

**Burger Town** is a Front-End restaurant website project focused on combining a modern visual interface with a smooth and engaging browsing experience.

The website is fully designed for Arabic users with **RTL support**, and includes categorized menu items, special offers, shopping cart interactions, customer reviews, and dynamic UI effects.

## 🚀 Features

- 🍔 Modern burger restaurant interface
- 🌐 Full Arabic RTL layout
- 📱 Responsive design
- 🏠 Attractive hero section
- 🔥 Animated announcement bar
- 🧭 Sticky navigation
- ⭐ Popular items section
- 🍽️ Categorized food menu
- 🥩 Beef burgers
- 🍗 Chicken burgers
- 👨‍👩‍👧 Family meals
- 🧅 Starters
- 🍟 Sides
- 🥤 Drinks
- 🥛 Milkshakes
- 🍰 Desserts
- 🎁 Special offers
- 🛒 Interactive shopping cart
- ⭐ Product ratings
- 📊 Animated statistics
- 🖼️ Unsplash food images
- ✨ CSS and JavaScript animations
- 📜 Smooth scrolling
- 📱 Mobile navigation
- 📞 Direct call-to-order button

## 🧰 Technologies

## 🍽️ Website Sections

### 🏠 Home
A welcoming hero section featuring the restaurant introduction, key highlights, and buttons for browsing the menu and ordering.

### ⭐ Popular Items
A section showcasing selected customer-favorite meals.

### 🍔 Full Menu
An interactive menu organized into multiple food categories.

### 🎁 Special Offers
Special deals for families, friends, and weekend customers with discounted prices.

### 🛒 Shopping Cart
Users can add meals and offers to the cart while the item count updates dynamically.

### 💬 Customer Reviews
A dedicated section for displaying customer ratings and experiences.

### 📞 Contact
A contact section for reaching the restaurant and placing orders.

## 🎨 Design

The design uses a warm restaurant-inspired color palette featuring:

- 🔴 Red
- 🟠 Orange
- 🤍 Cream
- ⚫ Dark text tones

The interface uses the **Cairo** font and is built around an Arabic RTL layout.
